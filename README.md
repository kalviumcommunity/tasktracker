# TaskTracker — Starter (Next.js + TypeScript)

A tiny task-list app. The layout, styling, data, types, and build setup are **already done**.
You complete **5 short `// TODO` tasks** so the app can add tasks from the input box.

## Run it

```bash
npm install
npm run dev     # open http://localhost:3000 — the 3 seed tasks already show
npm run build   # must finish with 0 errors once all TODOs are done
```

> `npm run dev` shows the app from the start. `npm run build` must still pass after your changes. Finish every TODO: the app stays unchanged if a TODO is left open.

## Where you work (only these 3 files)

| File | Tasks |
|------|-------|
| `app/tasks.ts` | Task 1 (priority emoji) |
| `app/TaskCard.tsx` | Task 2 (typed props + JSX) |
| `app/page.tsx` | Task 3 (`useState`), Task 4 (submit handler), Task 5 (form and controlled input) |

Do the tasks **in order** and follow the `// TODO` comments. Do **not** use `any`, and do not edit
the CSS, `tsconfig.json`, `next.config.mjs`, or `app/layout.tsx`.

## Submit

When the app runs and `npm run build` passes, **zip the project folder** (without `node_modules`)
and upload the `.zip`.

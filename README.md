# TaskTracker — Starter (Next.js + TypeScript)

A tiny task-list app. The layout, styling, data, and build setup are **already done**.
You only complete **5 short `// TODO` tasks** so the app becomes fully typed and interactive.

## Run it

```bash
npm install
npm run dev     # open http://localhost:3000 — the 3 seed tasks already show
npm run build   # must finish with 0 errors once all TODOs are done
```

> `npm run dev` shows the app from the start. `npm run build` (which runs the
> TypeScript checker) only passes **after** you finish the TODOs.

## Where you work (only these 3 files)

| File | Tasks |
|------|-------|
| `lib/tasks.ts` | Task 1 (Omit type), Task 2 (typeof narrowing) |
| `components/TaskCard.tsx` | Task 3 (typed props + JSX) |
| `app/page.tsx` | Task 4 (`useState`), Task 5 (events + controlled form) |

Do the tasks **in order** and follow the `// TODO` comments — each one tells you exactly
what to write. Do **not** use `any`, and do not edit the CSS, `tsconfig.json`, or `layout.tsx`.

## Submit

When the app runs and `npm run build` passes, **zip the project folder** (without
`node_modules`) and upload the `.zip`.
